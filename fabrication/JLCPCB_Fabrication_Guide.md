# 制造准备说明

当前设计未放行制造。请先完成 `../verification/AUDIT_REPORT.md` 和 `../validation_summary.json` 中的剩余检查；不要使用历史 Gerber 下单。

主板尺寸候选为 50×32 mm；FPC 三种候选总长为 36/40/45 mm。实际 SuperMini 模块尺寸、针脚和天线净空必须确认。FPC 的总插入厚度、插入宽度、接触长度、下接触方向、补强和表面处理必须与 FH12-6S-0.5SH(55) 原厂图和实际样品对账，不能仅按概念示意图下单。

采购参考：主板 10µF 0805=C440198，100nF 0603=C14663；探针 100nF 0402=C1525；连接器=C202118；温度传感器=C2803242；PTC=C152572。BOM 中的自定义铜结构与机械孔不是采购器件。排针为通孔器件，需另评估焊接方式。

CPL 为当前 PCB 的绝对坐标参考，采用 KiCad x/y 和旋转约定。正式 CAM、贴装原点、供应商旋转偏移和钢网必须在同一放行版本导出并复核；不能直接把这份参考 CPL 当作已经完成嘉立创贴装预览。

TMP117 中央焊盘的锡膏与焊接方式是温度测量的重要工艺项；本地候选取消锡膏，但原生库封装还需要独立复核。禁布区与细铜走线的热传导也必须实测。

[嘉立创官方 KiCad 导入说明](https://prodocs.lceda.cn/cn/import-export/import-kicad/index.html)列出的支持版本为 5.1/5.9，且说明铺铜导入行为差异。本项目使用 KiCad 10.0.6，不能承诺文件无缝迁移。Gerber 也不能替代带网络与器件关联的工程源。
