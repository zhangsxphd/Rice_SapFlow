# Rice SapFlow 优化验证记录

2026-10-03，在嘉立创 EDA 专业版 4.1.60 中修改、保存并重新读取了现有工程。当前交付源为项目根目录的 `Rice_SapFlow_Optimized.epro2`。本次没有运行 KiCad，没有烧录实物，没有下单制造。

当前结论：电路意图、引脚与焊盘映射、关键铜线通路和固件构建检查通过，可进入原型验证。尚未完成制造发布和茎流量标定。

## 实际修改

- 使用 HT7530-7 提供标称 3.0V 加热电源，配置输入、输出去耦；CE 与 AO3400A 的栅极共同控制，保留 100Ω 栅极电阻及 100kΩ 下拉。删除 SJ1，去掉 5V 旁路。
- 将过温检测用 PTC 更换为 470Ω、±0.5%、0.1W 的 YAGEO AC0603DR-07470RL。3V 下理论功率约 19.15mW；功率和温升需实测。
- 保留双 TMP117，地址为 0x48 和 0x49。传感器、加热器位于同一直线，传感器至加热器中心各约 2.997mm。
- J1/J4 使用同型号 FH12-6S-0.5SH(55) 底接触插座。当前连接采用两端插座及 FFC。母座位号统一为 J2/J3。实际 SuperMini 型号尚未确认。
- 修正六个测试点为单孔焊盘，排除出装配 BOM。探头 C5/C6 使用 100nF 0402，四个过孔移出焊盘；清理残留铜线和丝印压焊盘。
- 增加 ESP32-C3 固件：双温度单次转换采集、WiFi 温度曲线和 CSV、手动单次授权、独立定时关断、故障锁定。GPIO 开启与关断回调共享短临界区，避免过期回调关断后又被延迟执行的代码重新开启。

`intent_validation_final.json` 检查了全部 29 个部件的实际 pin/pad 网络、同板唯一身份、真实料号、测试点 DNP、地址绑定位和固件 GPIO。结果 `digitalChecksPassed=true`，23 个实际装配位置；主控模块和 FFC 为待确认的外购件，未伪造采购料号。

17 条关键通路通过 `pcb net-path` 的实际焊盘、导线和过孔图验证，包括 5V 至 U4、U4 输出至 FFC、CE/MOS 栅极、加热回流、两颗 TMP117 的 SDA/SCL 及两组去耦供电。该通路检查不推断覆铜连接；全板连接结果另以原生 DRC 为依据。

两轮 PCB 保存、重载和原生截图的语义 SHA-256 一致，渲染像素也一致。第一轮已检查两块板的布局；第二轮以新读回和相同渲染证明保存状态稳定。记录见 `two_round_visual_review.json`。原理图另外由原生对象导出 PNG 后检查。

固件用 Arduino ESP32 core 3.3.12、`esp32:esp32:esp32c3:CDCOnBoot=cdc` 编译通过，程序 1,044,127 字节（79%），静态 RAM 72,600 字节（22%）。主机状态测试通过：启动关闭、授权、脉冲上下限和截止、传感器过期、冷却限制、温升/温度故障、毫秒计数回绕、基线稳定、授权过期、无效样本及观测结束。它们未测试真实 I²C、无线链路或示波器关断时序。13 个 Python 文件语法检查通过。

## 未消除的告警与发布条件

主板原生 ERC 返回两条 warning 的计数，没有逐项对象或原因。重建式检查为 0 项，不能由此断言原生告警已消除。发布前需要在 EDA 的原生检查面板核对这两条告警。

DFM 审核保留实际告警，未放宽规则以改变结论：

- 两板的电源未铺铜和线宽建议合计各 6 条。探头保留走线供电以避免增加大面积导热铜；电流需求较小，但供电压降和热响应仍需实测。
- 主板另有 1 条 SDA/SCL 平行耦合建议、4 条电容距离建议。C1/C2 是模块接口的去耦，而 U4 输入另有近端 C7/C9；输出 C8/C10 至 U4 输出焊盘约 3.7/4.1mm，正式制造布局应复核并尽量靠近。3 条 info 涉及不同线宽和装配基准点。
- 当前 SuperMini 两排孔距为 17.78mm，固件按 GPIO4/3/1 对应 J2.4/5/7。模块完整型号、针脚方向、孔距及天线附近覆铜要求尚未与实物核对，因此不能保证任意品牌模块直接兼容。
- 需要验证 FFC 的同面/异面规格和逐针对应、探头柔性板工艺和装配、TMP117 EP/锡膏钢网处理。电气 NC 不代表钢网已排除 EP 锡膏。
- 需要示波器测量复位关断、3V 输出、负载电流、脉冲截止以及任务阻塞时关断；随后验证双传感器一致性、探头热点和可重复温升。
- 尚无水稻茎秆热耦合及零流量/已知流量数据，不能保证论文的量程或精度。固件当前返回原始温度和温升，`sap_flow=null`、`calibrated=false`。

实物验收顺序和接线见 `docs/OPTIMIZED_DESIGN.md`。本次没有交付新的生产 Gerber/钢网文件；项目中的旧制造文件不适用于优化版。
